# App Store screenshot mockups

Branded 1290×2796 (6.7" iPhone) mockups to preview how the App Store listing
will look — caption style, colours and composition. `gen.py` renders them from
HTML via headless Chromium.

These use stylised gradient placeholders, NOT real garment photos. For the actual
submission, capture real screens from the TestFlight/Simulator build and reuse
this caption/layout treatment (or drop the real screens into gen.py's frames).
